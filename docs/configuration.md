# Choose which carriers offer courier cash on delivery

Open **Cool Cat Ideas > CCI Courier Cash on Delivery**.

## Pick the carriers

Turn on each courier that collects the order value when the parcel is delivered. Leave parcel lockers, store pickup and other payment-on-receipt cases off unless the courier really handles the payment.

At least one carrier must be selected before you can save.

When you save, the module:

- shows its payment only for the selected carriers;
- removes those carriers from PrestaShop's standard cash-on-delivery module;
- returns carriers you deselected to the standard module.

This keeps the two payment choices from appearing together for the same carrier.

## Check the result

1. Start a new cart with a physical product.
2. Choose a selected courier.
3. Confirm that **Courier cash on delivery** appears as a payment choice.
4. Place the order and open it in the back office.
5. Check the payment name and order status.
6. Start another cart with an unselected delivery method and confirm that this payment is not offered.

The same carrier selection is used across the active shops returned by PrestaShop. If you use Multistore, repeat the checkout test in every affected shop.
